# Contributing

Thanks for adding to this. The useful contributions are concrete: a failure and how you found it,
a test that would have caught it, a template section you missed.

- **Questions and stories** go in [Discussions](https://github.com/LucaDeAng/deployment-strategist-hub/discussions).
- **Fixes to templates** are welcome as pull requests. Keep a template to one page, and keep each
  line a question a deployment review would ask.
- **New assets** (a repo, a notebook, a calculator): open an Idea first with what it measures and how
  to run it. Assets listed here need a README with a run command and a license.

Please anonymise everything: no employer, client or vendor names you are not allowed to share, no
customer data, ranges instead of internal figures. Synthetic examples are fine; say they are synthetic.

Be kind and specific. Disagree with the method, not the person.
